# assets/

Imported art, audio and fonts, by type. Everything here ships in the build.

- `fonts/` — the one pixel font (ADR-0008) and its licence file.
- `audio/` — the two placeholder sounds (D11) and their credits (`CREDITS.md`).
- `art/` — game art, created with its first asset; every image must match a canvas in
  `pixelforge.toml` (ADR-0006).

Every third-party file keeps its licence file next to it.
