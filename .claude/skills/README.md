# Project skills

Skills specific to this game go here, one folder each with a `SKILL.md`. The generic process
skills come from the `game-sdlc` plugin and the Godot ones from `game-sdlc-godot`, so don't copy
them in.

Codex reads mirrors of these from `.agents/skills/`. After any change here, run
`python3 .agents/scripts/sync_skills.py --write`; never edit the mirrors by hand.
